# IVAN_TUTOR — Сайт-визитка репетитора по химии и математике

Современный лендинг для репетитора Ивана, который готовит школьников к ОГЭ и ЕГЭ по химии и математике.

## 🚀 Технологии

- **React 18** — библиотека для построения пользовательских интерфейсов
- **TypeScript** — типизация для надёжного кода
- **Vite** — быстрый сборщик и инструмент разработки
- **Framer Motion** — библиотека для анимаций
- **Tailwind CSS** — утилитарный CSS-фреймворк для стилизации

## 📦 Установка и запуск

### Требования
- Node.js (версия 18 или выше)
- npm

### Установка зависимостей

```bash
npm install
```

npm install @emailjs/browser

### Запуск в режиме разработки
```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:5173

### Сборка для продакшена
```bash
npm run build
```

### Структура проекта
```text
src/
├── components/
│   ├── blocks/          # Основные блоки лендинга
│   │   ├── Hero.tsx     # Первый экран
│   │   ├── Stats.tsx    # Цифры и достижения
│   │   ├── About.tsx    # О репетиторе
│   │   ├── Services.tsx # Услуги и цены
│   │   ├── HowItWorks.tsx # Схема работы
│   │   ├── Reviews.tsx  # Отзывы
│   │   ├── SocialProof.tsx # Разборы из соцсетей
│   │   ├── FAQ.tsx      # Вопросы-ответы
│   │   └── Footer.tsx   # Нижняя часть с контактами
│   └── ui/              # Переиспользуемые UI-компоненты
├── types/
│   └── index.ts         # Общие TypeScript-типы
├── styles/
│   └── index.css        # Глобальные стили и Tailwind
├── App.tsx              # Корневой компонент
└── main.tsx             # Точка входа
```

### Особенности дизайна

- Цветовая схема: глубокий синий (#1a2a4a), белый, акцентный золотой/оранжевый (#f59e0b)
- Плавные анимации при скролле
- Адаптивная вёрстка под все устройства
- Интерактивные элементы (пульсирующие кнопки, накручивающиеся цифры, аккордеон)
